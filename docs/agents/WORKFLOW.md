# Agent System V2 Workflow Index

This compatibility path indexes the canonical six-stage issue lifecycle. It does not
duplicate stage procedures or create another engineering queue.

## Lifecycle

1. [`01-orient/CONTEXT.md`](01-orient/CONTEXT.md) — reconcile live authority,
   select eligible work, and preserve unknown state.
2. [`02-shape/CONTEXT.md`](02-shape/CONTEXT.md) — resolve scope, acceptance, journey,
   risk, exclusions, and proof needs.
3. [`03-implement/CONTEXT.md`](03-implement/CONTEXT.md) — reproduce, test, and apply
   the minimum root-cause repair.
4. [`04-verify/CONTEXT.md`](04-verify/CONTEXT.md) — complete pre-freeze work, form the
   exact candidate, run final review, and prove exact-SHA CI.
5. [`05-hosted-proof/CONTEXT.md`](05-hosted-proof/CONTEXT.md) — when required, run one
   authorized hosted transaction and exact cleanup.
6. [`06-complete/CONTEXT.md`](06-complete/CONTEXT.md) — merge, close, reconcile,
   remember, clean, report, and stop.
