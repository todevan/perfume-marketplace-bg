# Stage 06 — Complete

## Job

Merge proven work, reconcile every live state surface, preserve sanitized learning,
and stop before unauthorized work.

## Inputs

- Stage 04 exact candidate evidence and Stage 05 proof when required
- Live pull request, required reviews/checks, issue, labels, branches, and worktrees
- [`../reference/MEMORY.md`](../reference/MEMORY.md)
- [`../reference/WORKTREES.md`](../reference/WORKTREES.md)

## Procedure

1. Finalize the PR with issue outcome, changed-file/acceptance map, exclusions,
   candidate/base/tree identities, tests, reviews, CI, and hosted evidence when
   applicable.
2. Re-read live issue approval and scope, then merge only through the normal
   protected path when all exact-candidate gates pass. Merge and deploy are separate.
3. Verify merge SHA and PR state; for issue-backed work also verify issue closure and
   labels. Verify absence of unintended issue activation from live GitHub.
4. Update [`../../PROJECT-STATUS.md`](../../PROJECT-STATUS.md) only when verified
   repository, product, deployment, hosted-system, or operational truth changed.
5. Write one sanitized Engram closure observation and supersede older active
   checkpoints. Store no transcript or secret material.
6. Classify and remove branches/worktrees only under the exact worktree safety
   contract; synchronize the canonical clone only when its local state permits it.
7. Report launch progress, active and blocked issues, next verified-unblocked issue,
   owner action, technical evidence, outcome, sync state, authorized continuation,
   and stop condition. Stop before the next issue unless explicitly authorized.

## Output

Verified merge and issue closure when applicable, reconciled active state,
current-truth documentation, sanitized memory, safe cleanup, and a live evidence
handoff. Zero active product issues is a valid terminal state.

## Human gate

none — agent-owned unless normal repository policy or R3 requires one exact protected
owner action

## Stop conditions

- Any required check, review, proof, cleanup, or live closure evidence is missing.
- Merge requires a protected owner action not already authorized.
- Canonical or historical work cannot be classified safely.
